# 宝塔面板安装说明（OpenCloudOS / CentOS / Ubuntu 都适用）

和原来的未央装在同一台服务器上也没问题：原未央用 `/opt/jarvis`、端口 8787、账号 `jarvis`；这里用 `/opt/weiyang-agent`、端口 8797、账号 `weiyang`，安装脚本一样也不碰原未央。

> 下面每条命令都是**一行**，在宝塔终端（root）里一条一条粘贴执行。宝塔手机 App 终端粘多行会被拼成一行，所以不要一次粘好几条。

## 一、准备

1. **域名解析**：在域名服务商加一条 A 记录，比如主机记录 `e`，指向服务器公网 IP。已经加过就跳过。
2. **Node.js 20 以上**：宝塔 → 软件商店 → Node.js 版本管理器，装 v22，点“设为命令行版本”。终端里检查：
   ```
   node -v
   ```

## 二、安装

1. 下载程序（服务器连得上 GitHub 时）：
   ```
   cd /opt && git clone https://github.com/xunova1121/weiyang-agent.git
   ```
   直连卡住不动（国内常见）就按 Ctrl+C，改走加速镜像：
   ```
   cd /opt && git clone https://ghfast.top/https://github.com/xunova1121/weiyang-agent.git && git -C weiyang-agent remote set-url origin https://github.com/xunova1121/weiyang-agent.git
   ```
   连不上 GitHub：在电脑上打开仓库页面 → Code → Download ZIP，用宝塔“文件”上传到 `/opt` 解压，把解压出来的 `weiyang-agent-main` 文件夹改名为 `weiyang-agent`。

2. 运行安装脚本：
   ```
   bash /opt/weiyang-agent/deploy/install.sh
   ```
   - 会让你设**登录密码**（至少 8 位，输两次）和填 **DeepSeek 密钥**，输入时屏幕上不显示。它们只写进服务器上的 `/etc/weiyang-agent.env`（只有 root 能读），不会进仓库，也不用发给任何人。
   - 依赖走国内镜像，一般 1～3 分钟。最后看到“好了：未央 Agent 版已在运行”就成功了。
   - 日志里会写“跑命令已开放”或“未开放”及原因。没开放也能正常聊天、读写文件。

## 三、宝塔里配置网站

1. **添加站点**：网站 → 添加站点，域名填你的域名（如 `e.example.com`），PHP 选“纯静态”，不建数据库。
2. **证书**：网站设置 → SSL → Let's Encrypt → 申请，打开“强制 HTTPS”。
3. **反向代理**：网站设置 → 反向代理 → 添加
   - 目标 URL：`http://127.0.0.1:8797`
   - 发送域名：`$host`
   - **不要开缓存**。
4. **改配置**：
   - 网站设置 → 配置文件，在 `server {` 下面加一行（上传文件最大 20MB，留点余量）：
     ```
     client_max_body_size 25m;
     ```
   - 反向代理那一行点“配置文件”，在 `location` 里面加（不加的话回复会攒着一下子才出来，或长任务中途断开）：
     ```
     proxy_buffering off;
     proxy_read_timeout 3600s;
     ```

腾讯云安全组不用新开端口（8797 只在服务器内部用，对外走 443）。

## 四、检查

1. 在服务器上做一遍冒烟检查（会真的调用 DeepSeek 几次，花一点点额度）：
   ```
   cd /opt/weiyang-agent && set -a && . /etc/weiyang-agent.env && set +a && node test/server.smoke.mjs http://127.0.0.1:8797
   ```
2. 手机或电脑浏览器打开 `https://你的域名`，用刚设的密码登录，问一句话。

## 自动更新

用 `git clone` 装的，安装脚本会顺带装上自动更新：每 30 分钟检查一次，有新版本就自己装好，不用你动手。

- 只装 GitHub 上自动测试全过的版本（`stable` 分支）。
- 有回复正在进行时先不更新，下一轮再试；连不上 GitHub 也是下一轮再试。
- 国内服务器直连 GitHub 常常不通：会依次走加速镜像（ghfast.top、gh-proxy.com、ghproxy.net）。镜像是别人的服务器，所以经镜像拿到的版本要和 GitHub 接口（api.github.com）给的版本编号核对一致才装；接口也连不上时默认不装。想像原未央一样直接信任镜像，在 `/etc/weiyang-agent.env` 加一行 `UPDATE_TRUST_MIRROR=1`。
- 依赖有变化时先在旁边装好再换，装不上就不动正在用的版本。
- 新版本起不来会自动退回上一个版本，并且不再反复试这个版本。
- 不碰你的密码、密钥和对话数据。

看更新记录：`journalctl -u weiyang-agent-update -n 30 --no-pager`；想马上更新一次：`bash /opt/weiyang-agent/deploy/update.sh`；不想自动更新：`systemctl disable --now weiyang-agent-update.timer`。

## 常用操作

| 要做什么 | 命令 |
|---|---|
| 看日志 | `journalctl -u weiyang-agent -n 50 --no-pager` |
| 重启 | `systemctl restart weiyang-agent` |
| 马上升级（平时自动） | `bash /opt/weiyang-agent/deploy/update.sh` |
| 连 GitHub 报 Empty reply | 命令里的 `git` 换成 `git -c http.version=HTTP/1.1` 再试；自动更新已经这样做了 |
| 改密码或密钥 | 编辑 `/etc/weiyang-agent.env`，再 `systemctl restart weiyang-agent`（所有设备要重新登录） |
| 备份 | 打包 `/var/lib/weiyang-agent` 整个文件夹（对话记录和工作文件夹都在里面） |
| 停用 | `systemctl disable --now weiyang-agent` |

## 没验证过的

- OpenCloudOS 的软件源里有没有 bubblewrap、socat，以及装上后沙箱能不能起来（Ubuntu 24.04 在 GitHub 自动测试里验证过）。起不来时日志会说明原因，运行命令不开放，其他功能不受影响。
- 接真实 DeepSeek 的回复效果和速度。
